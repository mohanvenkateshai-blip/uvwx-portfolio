01 — Flagship

Prompt to production — generative UI at Ericsson scale.

The EDS MCP AI Agent — an agentic system I led the UX for at Ericsson: developers describe the interface in plain language; the agent builds it to design-system spec, with a human in command.

ClientEricsson
Year2024 — 2025
RoleUX Lead, Agentic Experience
DisciplineInteraction model · Trust & control patterns · AI validation loops
StackMCP · ReAct · Figma · Amazon Q · VS Code

Developers spent days hand-building dashboards against the Ericsson Design System — and still shipped non-compliant UI that design teams had to rework.

The design problem wasn't code generation — it was trust. An agent that silently writes UI is a liability; an agent developers can direct, inspect and correct is a force multiplier. Three decisions shaped the experience:

  1. The human stays in command

    Every generation is a proposal. Developers review, refine or reject before anything lands — no silent automation, ever.

  2. Ground the agent in the design system

    The agent reads live component specs from Figma and validates its own output against EDS rules — compliant by construction, not by review.

  3. Design for iteration, not one-shot magic

    Conversational refinement — “make the table filterable” — replaces prompt-perfectionism, matching how developers actually work.

→
Outcome

A single prompt now produces a complete, EDS-compliant dashboard — 100% design-system components, zero custom CSS — with the developer approving every step. Hours of hand-built UI work replaced by a directed, inspectable generation loop.

Usability programmes · Ericsson · Global telecoms

Research practice — one story

Method. Moderated usability studies and heuristic evaluations across programmes with Tier-1 operators — Telstra, Optus, Swisscom, T-Mobile — on Ericsson Service Orchestration & Assurance. Full decks under NDA, available on request.

What we found. A heuristic evaluation across 200 guidelines and 9 usability categories with 5 UX experts established a 72% baseline and surfaced 28 UX issues — 5 critical, 10 major, 13 minor. A separate evaluative study quantified a 35% task-failure rate across 20 pre-release task attempts.

What changed. Findings were synthesised into roadmap-ready GA fixes: navigation, data-rich table usability, role-based status visibility, advanced filters, exception handling and empty-state messaging.

Result. All 28 issues were closed before GA. Customer validation with Telstra and Optus users achieved 100% completion across 15 required task attempts, and 12 improvements shipped in the GA release.
