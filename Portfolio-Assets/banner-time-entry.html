Banner Time Entry

A responsive web application for time and leave management that includes employee, supervisor and super-admin as personas. This was legacy application (part of HR product suite) with very old and not much user friendly UI which was to be enhanced to be more easy, intuitive and useful interface and IA keeping in line with the existing global standards from the product suite. It needed thorough study of what we have and what new we can introduce to maintain the scope and how we can stay competitive in the market. We introduced new views (e.g. calendar view ) and features (e.g. team availability) to make it more useful.
