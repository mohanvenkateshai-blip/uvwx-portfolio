My Finance Query

Create, view and share budget availability, encumbrance and payroll queries.

Banner My Finance Query provides an enhanced user experience to view remaining balance for easier financial management. Adds quick views of spend analysis through graphics and dashboards. Allows drill-down capability from summary to document level including attachments. Leverages embedded reporting to make better business decisions. It allows the user to compare financial data across user defined time-frames by providing the ability to configure views of preferred funding elements. My Finance leverages existing Banner database for historical trend analysis with RWD for cross platform compatibility.
